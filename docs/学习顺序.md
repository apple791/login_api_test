# 当前阅读与运行顺序

更新日期：2026-10-18。

1. config.py：BASE_URL、接口地址、TIMEOUT、DB_PATH，确认服务与数据库对应。
2. 根conftest.py：独立账号、登录、请求体、三条明细和数据库连接的fixture，理解yield关闭连接。
3. 账号用例：test_register、test_login、test_me、test_auth、test_logout、test_change_password。
4. 账本用例：test_transaction_create、amount、permissions、sessions、list。
5. test_transaction_db.py：金额入库、非法金额不入库、接口列表与SQL核对、分类汇总。该文件内部ledger_account夹具只服务SQL测试，不影响其他模块。
6. ledger.py：金额转换、校验、用户范围、列表筛选与详情；app.py：账号鉴权、会话失效与数据库连接。
7. tests：独立服务验收，理解其与默认真实HTTP用例的区别。

先启动 python app.py，再运行 python -m pytest test_cases -q。当前共107条，其中SQL核对12条。运行 python -m pytest tests -q 为119条独立服务验收，不需启动服务；数量有重叠，不合并统计独立场景。

SQL学习已接入自动化：参数化SELECT、fetchone/fetchall、sqlite3.Row、COUNT、GROUP BY与SUM。check_db.py为早期手工查询示例，不是回归入口。旧practice目录已归档，不再使用旧路径。

接口规则见账本接口第一阶段，逐文件数量见测试用例。后续尚未实现修改、删除或统计接口。
