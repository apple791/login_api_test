# 整理后的阅读与运行顺序

1. config.py：BASE_URL、各接口PATH和URL、TIMEOUT，理解路径不再分散在用例中。
2. conftest.py：registered_user注册独立账号；logged_in_user依赖前者并登录。
3. test_cases/test_register.py：先读长度参数化，再读重复用户名。
4. test_cases/test_login.py：正确登录、错误输入与响应断言。
5. test_cases/test_me.py和test_auth.py：缺少Token及错误认证组合。
6. test_cases/test_logout.py：当前会话失效、其他会话不受影响、重复退出。
7. test_cases/test_change_password.py：成功/失败后的状态变化、边界、多会话和跨账号。
8. 最后阅读app.py中的校验与存储，不必先研究JWT算法。

你的39条测试需要先运行app.py；原有tests目录的81条测试自动启动临时服务。两者执行方式不同，README有对应命令。不要继续使用已迁移的practice/test_login.py路径。
