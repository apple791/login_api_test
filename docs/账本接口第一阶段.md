# 账本接口第一阶段

本阶段提供新增、列表、详情三个接口；沿用账号系统的 Bearer Token。旧教学缺陷模式仅作用于原账号练习，账本接口始终鉴权。

## 启动与验证

在项目目录运行：
```powershell
python app.py
python -m pytest tests/test_ledger.py -q
```
自动验收使用 Flask 测试客户端和临时 SQLite 数据库，不需要先启动服务，不会写入你的练习数据库。`test_cases` 中的 Requests 练习已整理为五个接口测试文件及一个SQL核对文件，仍需启动服务；其中SQL文件必须配置与服务匹配的DB_PATH。此处测试由 AI 辅助编写，理解并复现后再作为个人测试成果介绍。

## 1 新增收支

`POST http://127.0.0.1:5001/api/transactions`

请求头：`Authorization: Bearer 登录返回的token`

JSON请求体：
```json
{"type":"expense","amount":"12.50","category":"food","date":"2026-10-18","note":"午餐"}
```

字段规则：
- type：必填，仅 income（收入）、expense（支出）。
- amount：必填字符串，0.01～999999.99，最多两位小数。允许 "100"、"12.5"、"12.50"；不接受数字类型、空格、正负号、科学计数法。整数部分1～6位，允许前导零；返回统一两位小数。数据库以整数分保存。
- category：必填。收入为 salary、bonus、other_income；支出为 food、transport、shopping、other_expense。
- date：必填真实日期，严格 YYYY-MM-DD；第一版允许未来日期，不设额外日期区间限制。
- note：可省略，默认空字符串；最多200个字符，null不合法。
- 记录归属由Token决定，不采信客户端传入的用户ID；其他未定义字段忽略。

新增成功201：data包含 id、type、amount、category、date、note。参数不合法400且data=null，不能新增数据；无效或缺少Token401。先校验身份，再校验参数。

## 2 查询列表

`GET /api/transactions?page=1&page_size=20&type=expense&category=food`

均为可选参数；page正整数（最多9位），page_size为1～100。按ID倒序。type和category按上述枚举筛选，组合筛选无匹配时返回空列表。未识别的查询参数忽略。

200示例：
```json
{"code":200,"message":"查询成功","data":{"items":[],"total":0,"page":1,"page_size":20}}
```
只统计和返回当前用户的数据，分页超出范围时items为空。非法筛选或分页参数400。

## 3 查询详情

`GET /api/transactions/1`

当前用户自己的记录返回200；记录不存在或属于其他用户统一404、data=null。无Token401。拒绝查询不会修改原记录。

## 数据库核对

数据库路径：`instance/correct.db`（正常模式）。可用数据库工具打开：
```sql
SELECT id, user_id, type, amount_cents, category, date, note
FROM transactions ORDER BY id DESC;
```
12.50元保存为1250分。先查询记录总数，再发送非法金额请求，确认返回400且记录数不增加；结合用户ID和记录ID核对，避免把其他请求的数据误认成本次写入。

## 推荐练习顺序

1. 先注册登录，用Postman新增12.50元支出，记下ID。
2. 用相同Token查询列表和该ID，核对全部字段。
3. 测试金额0.00、0.01、999999.99、1000000.00，分别预期400、201、201、400。
4. 使用12.501验证小数位规则；请求前后核对数据库。
5. 注册第二个用户，用第二个Token查询第一个用户的记录，预期404；第二个用户的列表为空。
6. 阅读 test_cases/test_transaction_create.py 的新增查询流程，再学习金额、权限、列表及test_transaction_db.py中的SQL核对。tests/test_ledger.py是另外的自动服务验收入口。

范围：本阶段不实现修改、删除、月度统计，也没有增加账本教学缺陷开关。
