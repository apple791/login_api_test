# 等价类与边界值测试用例

本项目使用以下约定，而非所有网站通用的密码规则：ASCII 字母和数字，密码 6～16 位、用户名 3～20 位，包含上下限，区分大小写。

测试长度时只改变长度；测试用户名时使用 8 位有效密码；测试登录前先断言注册成功。

| 用例组 | 输入或步骤 | 正确模式预期 | 用例数 |
|---|---|---|---:|
| 密码长度 | 3、5、6、7、10、15、16、17、20 位；内容为重复 a | 3、5、17、20 返回 400，其余 201 | 9 |
| 密码无效类 | null、空串、数字、布尔、数组、对象、空格、中文、特殊符号 | 400 | 9 |
| 缺少密码 | 只传合法 username | 400 | 1 |
| 用户名长度 | 2、3、4、19、20、21 位 | 2、21 返回 400，其余 201 | 6 |
| 注册请求无效类 | 无请求体、数组、缺 username、username=null、数字、空格 | 400 | 6 |
| 重复用户名 | 相同数据注册两次 | 第一次 201，第二次 409 | 1 |
| 完整流程 | 注册→登录提取 Token→查询个人信息 | 201→200→200，id 与用户名一致，不返回密码字段 | 1 |
| 错误凭据 | 不存在用户、已注册用户的错误密码 | 401、统一错误提示、不返回 Token | 2 |
| 登录参数错误 | 空对象、缺密码、密码 null、数字、请求体数组 | 400 | 5 |
| 无 Token | GET /api/me | 401 | 1 |
| 错误 Token | 错误签名文本、无 Bearer、Basic、空 Bearer | 401 | 4 |
| 原有用例小计 | 独立临时数据库与真实 HTTP 请求 | 不以数量代替业务覆盖率 | 45 |
| 新密码长度 | 3、5、6、7、10、15、16、17、20 位；同时验证保存后的登录密码 | 3、5、17、20 返回400，其余200 | 9 |
| 新密码无效类 | null、空串、数字、布尔、数组、对象、空格、中文、符号 | 400，原密码与原 Token 仍有效 | 9 |
| 改密请求无效类 | 无请求体、数组、空对象、缺新/原密码、原密码 null/数字/空串 | 400，原 Token 仍有效 | 8 |
| 改密拒绝 | 原密码错误、新旧密码相同 | 分别401、400，原凭据不受影响 | 2 |
| 改密完整流程 | 同账号登录两次，改密，检查全部旧 Token、旧/新密码及其他账号 | 旧 Token 全部401、旧密码401、新密码200；其他账号有效 | 1 |
| 退出完整流程 | 同账号登录两次，退出其中一次，再访问、重复退出及改密 | 当前 Token 均401；另一次登录及其他账号有效；仍可重新登录 | 1 |
| 新接口鉴权 | 两接口各测缺失 Token、无效 Token、错误认证方式 | 401 | 6 |
| 全部总计 | 正确模式完整回归 | 81项 | 81 |

密码长度的有效等价类是 6～16，小于 6 和大于 16 是两个无效等价类。代表值选 10、3、20；边界值选 5、6、7、15、16、17。这些用途可以重叠，不必重复创建含义完全相同的测试。

当前测试没有覆盖所有规则组合，例如 Token 自然过期、非法 JSON、全数字密码、大小写区分和并发重复注册尚可作为后续扩展，不能声称全覆盖。
